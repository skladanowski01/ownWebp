# ⚡ Pablo - Minimalist Web Developer Portfolio & Offer Page

![Portfolio Preview](assets/imgs/technologia.jpg)

A modern, high-performance landing page and commercial offer site built with a focus on minimalism, smooth animations, and clean code. Designed to deliver an exceptional User Experience (UX) across all devices.

🚀 **Live Site:** [pablo-stronyinternetowe.vercel.app](https://pablo-stronyinternetowe.vercel.app/)  
👨‍💻 **Developer Portfolio:** [skladanowski01.github.io/PabloPortfolio](https://skladanowski01.github.io/PabloPortfolio/)

---

## 🌟 Key Features

* **Glassmorphism & Minimalist UI:** Elegant dark theme with modern glassmorphism overlays and interactive elements.
* **Interactive Modal System:** Smooth GSAP-powered modals showcasing core services (SEO, RWD, GSAP, Minimalist Design).
* **Smooth Scrolling Experience:** Powered by [Lenis](https://lenis.darkroom.engineering/) for ultra-fluid page navigation.
* **Scroll-Triggered Animations:** Seamless reveal animations powered by [GSAP ScrollTrigger](https://gsap.com/scrolltrigger/).
* **Fullscreen Navigation:** Animated fullscreen overlay menu integrated with smooth scrolling lock.
* **SEO & Social Optimization:** Fully configured Open Graph, Twitter Cards, and canonical links.
* **Mobile First & Responsive:** Optimized for smartphones, tablets, and 4K displays.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox/Grid, Glassmorphism)
* **Logic & Interactivity:** JavaScript (ES6+)
* **Animation & Motion:** GSAP (GreenSock Animation Platform) + ScrollTrigger
* **Smooth Scroll:** Lenis Smooth Scroll
* **Deployment & Hosting:** Vercel
